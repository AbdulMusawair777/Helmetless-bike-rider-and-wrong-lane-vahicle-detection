Project Structure
Folder layout and how every file connects
Folder layout
your_project/ ├── app.py # Flask API server ← NEW ├── pipeline.py # detection engine ├── database.py # SQLite store ├── report.py # CSV exporter ├── dashboard.html # this UI ├── requirements.txt ├── requirements_web.txt # flask + flask-cors │ ├── models/ │ ├── motorcycle_best.pt │ └── plate_best.pt │ └── output/ auto-created ├── violations.db ├── snapshots/ └── reports/ └── <session_id>/ ├── wrong_direction.csv ├── no_helmet.csv ├── both_flags.csv └── all_violations.csv
How files connect
app.py
Flask server. Serves dashboard.html, exposes /api/* endpoints, runs pipeline.py as subprocess with live log streaming to the UI.
dashboard.html
This UI. Polls /api/pipeline/status every 1.5 s during a run. Reads violations, plates, sessions live from /api/*.
pipeline.py
Loads YOLO models, tracks motorcycles, calls database.py to store each violation exactly once, writes live CSVs via report.py.
database.py
UNIQUE(session, track_id, violation_type) + INSERT OR IGNORE guarantees no duplicate rows ever exist.
Quick start — 3 commands
pip install -r requirements.txt
pip install -r requirements_web.txt
python app.py
